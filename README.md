# CashU — تتبّع المصاريف وتسجيل رسائل البنك تلقائيًا (Flutter)

> أُعيدت تسمية التطبيق من «تيّار» إلى **CashU** (معرّف الحزمة `com.cashu.cashu`، رابط العودة `com.cashu.cashu://auth`).
> مفاتيح البيانات المزامَنة (`tyr_*`) وجدول `werd_sync` بقيت كما هي عمدًا حتى لا تفقد بياناتك على Supabase.

## التشغيل عبر GitHub
1. ارفع محتوى المجلد إلى مستودع (فرع `main`).
2. الـ workflow `.github/workflows/android-release.yml` يبني APK ويضعه في Release باسم `latest`.
3. أسرار اختيارية: `SUPABASE_ANON_KEY`, `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
4. تسجيل الدخول بجوجل: أضف `com.cashu.cashu://auth` في Supabase → Authentication → Redirect URLs.

## الجديد
- شريط سفلي زجاجي بثلاث تبويبات: الحسابات · الاشتراكات · التقارير (الإعدادات من صورة الحساب، الميزانيات من بطاقة الحسابات).
- تعريب كامل مع تبديل **عربي / English** (اتجاه الواجهة RTL/LTR تلقائيًا) من الإعدادات → اللغة.
- حجم الواجهة قابل للضبط (صغير/متوسط/عادي) ويصغّر كل شيء بتناسق، ويتجاهل تكبير خط النظام.
- سحب الحساب (يمين/شمال) بحركة نابضة، والأرشفة/الحذف بأنيميشن طيّ.
- أيقونة الحساب: مكتبة أيقونات، رفع صورة من المعرض، أو سحبها من رابط (تُخزَّن داخل التطبيق).
- **تتبع رسائل البنك** (الإعدادات → تتبع رسائل البنك):
  - Kotlin `SmsReceiver` + `SmsEngine` يعملان حتى والتطبيق مغلق: استبعاد OTP والعمليات الفاشلة، تصنيف بالكلمات المتتبَّعة (قابلة للتعديل)، استخراج المبلغ/العملة/آخر 4 أرقام/التاجر، ربط البطاقة بحساب.
  - قرار تلقائي: تسجيل مباشر / مراجعة / استبعاد، مع إشعار، وسجل، ومراجعة، ومسح الرسائل القديمة، وتجربة رسالة.
  - زر **الذكاء الاصطناعي** (Gemini / Claude / OpenAI-متوافق) بمفتاحك الخاص، يُحفظ محليًا ولا يُزامَن.
